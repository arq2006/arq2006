## 🚀 Projeto em destaque

### 📸 Solenne

<div align="left">

[![Solenne](https://img.shields.io/badge/Conhecer%20o%20Solenne-Acessar%20Projeto-111111?style=for-the-badge&logo=googlechrome&logoColor=white)](https://solenne.capture.app.br)

</div>

O **Solenne** é uma plataforma de compartilhamento colaborativo de fotos para eventos.

A proposta é permitir que convidados acessem um evento através de um **QR Code ou link público**, enviem suas fotos e contribuam para uma galeria compartilhada enquanto o organizador mantém o gerenciamento do evento.

O projeto envolve diferentes áreas do desenvolvimento de software, incluindo:

- Frontend moderno e responsivo;
- Backend com arquitetura modular;
- APIs REST;
- Autenticação;
- Banco de dados PostgreSQL;
- ORM;
- Gerenciamento de usuários e eventos;
- Upload e gerenciamento de mídia;
- Assinaturas e pagamentos;
- Painéis administrativos;
- Segurança;
- Docker;
- Infraestrutura em nuvem;
- Deploy de aplicações.
